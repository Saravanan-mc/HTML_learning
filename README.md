## 📘 Description 
This repository is a comprehensive, hands-on guide to HTML5. It covers the most important elements, attributes, and best practices for structuring web pages. It includes practical examples, exercises, and media files to demonstrate everything from basic text formatting to embedding multimedia, building forms, and utilizing modern semantic elements.

---

## 📂 Repository Structure
This repository contains a main HTML file and several media files to demonstrate how different HTML media tags work in a real-world scenario.

* 📄 `index.html` — The main working file containing all HTML code examples.
* 🖼️ `Sample.png` — Used to demonstrate the `<img>` tag.
* 🎵 `Sample.mp3` — Used to demonstrate the `<audio>` tag.
* 🎥 `Sample.mp4` — Used to demonstrate the `<video>` tag.
* 📕 `Sample.pdf` — Used to demonstrate `<iframe>`, `<embed>`, and `<object>` tags.

---

## 📖 What You’ll Learn

✅ **Basic HTML structure:** (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
✅ **Text Formatting:** Headings (`<h1>` to `<h6>`), paragraphs (`<p>`), and formatting tags (`<strong>`, `<em>`, `<mark>`, etc.)
✅ **Semantic Elements:** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
✅ **Lists:** Ordered (`<ol>`), Unordered (`<ul>`), and Description (`<dl>`) lists
✅ **Tables:** Structuring data with `<table>`, `<tr>`, `<th>`, and `<td>`
✅ **Forms & Inputs:** Text, email, password, radio buttons, checkboxes, dates, file uploads, and submit buttons
✅ **Links:** Standard links (`href`), email links (`mailto:`), and phone links (`tel:`)
✅ **Media:** Embedding images, audio, video, iframes, and external objects
✅ **Graphics:** SVG and Canvas basics
✅ **Interactive Elements:** (`<dialog>`, `<details>`, `<summary>`, `<progress>`, `<meter>`)
✅ **Scripting:** How to link JavaScript using `<script>` & `<noscript>`
✅ **Deprecated Tags:** Mentioned for historical understanding and legacy code maintenance

## 🚀 Why Learn HTML?

* 🌍 **Foundation of the Web:** Every website on the internet uses HTML.
* 🧩 **The Perfect Trio:** Works seamlessly alongside CSS (for styling) and JavaScript (for logic/interactivity).
* 💻 **Essential Skill:** A mandatory starting point for frontend development and UI/UX design.
* 📱 **Accessibility & SEO:** Semantic HTML helps build responsive, accessible, and search-engine-friendly web pages.
* 🎯 **Stepping Stone:** Prepares you to master modern frameworks like React, Vue, and Angular.
